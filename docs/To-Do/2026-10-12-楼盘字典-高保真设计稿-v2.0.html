01 · 背景
为什么现在做
项目地址一直是 小区名 + 手填门牌（community_name + address），无结构化楼栋/户室，无法支撑按楼栋估价、同小区比价与钥匙定位。现已获得上海全域楼盘字典原始数据，具备落地条件。
02 · 数据规模
四级字典体量
约 1.97 万小区 / 52.7 万楼栋 / 733 万户室记录（户室号前两位解析为楼层）；97% 小区带经纬度锚点。数据为 2017 年快照，需以「基础字典 + 运营修正」的口径使用。
03 · 本稿范围
可交互原型 + 编号化需求规格
五个页面真实联动 + SEC 04 需求规格浓缩版（FR-01~18 / BR-01~23 / NFR-01~07 / 状态机 / 验收标准）；权威完整版见《2026-10-12-楼盘字典-需求规格说明书.md》（含需求追溯矩阵，v1.0~v1.6 共 22 条反馈全部映射，未审核楼栋/楼层/户室全系统可见带标签）。地图视图不在本期（坐标 BD-09 已就位）。

关注点决策说明

楼栋/户室解析保留原始串楼栋号「201乙」「惠园路2000弄01」不做数字抽取；楼层为呈现层字段：户室号前两位数字解析为 floor（0401→4 层），非标户室（0233-1 等）floor=NULL 归「未分层」组，落库存原值
楼层层级随户室自动生成不建 bd_floors 表、无「单独新增楼层」：某层随该层首个户室创建而出现（floor 可空解析自户室号）；字典端补录户室时填写新楼层号即隐式建层（即时生效）；录入端提供「＋添加新楼层」快捷入口 = 提交该层首个户室（进审核池）；空层（架空层/设备层）不入字典，仅在楼栋维度记录总层数展示
字典端补录admin 直接生效字典端添加小区/楼栋/户室（原型页 01）为可信操作，即时写入并留审计；支持批量区间语法：楼栋「29-55」、楼层「7-12」、户室「01-08」笛卡尔展开，uq 跳过已有，单次上限 60 栋 / 200 户；与录入端提交（进审核池）分开
审核池bd_pending_entrieskind = community / building / room（含来源单据与提交人，v1.8 来源泛化：项目/线索/营销/房源；v1.9 增 bd_pending_references 引用账本 + uq_pending_open 同名唯一 + parent 父子层级），审核动作三选一：合并现有 / 通过新增 / 驳回；驳回按来源分流（BR-27）：录入端当场改选、机器/C 端落 rejected 转运营待办；pending 终态 = merged / created / rejected；小区新增不阻塞业务创建——单据先落库，小区审核通过后自动回填转正，转正前单据名称显示「未审核」标签
审核权限默认 admin · 可配置审核池处理人默认 admin，通过 system_configs 键 building_dict_reviewer_roles 配置可处理角色；字典端补录/小区新增限 admin
全模块统一入口新增一律走字典线索/项目/营销等各模块新增时的地址录入统一复用楼盘字典四级选择器（小区→楼栋→楼层→户室，含新增小区/楼栋/楼层/户室入口；线索/营销小区必选、楼栋/户室选填落库，v1.8）；存量数据（项目/线索/营销/房源四类，v1.9）支持手动「关联字典」（原型页 05），关联确认后数据层以字典数据为准（building_id / room_id / community 关联生效，项目原手填地址转备注保留、其余 community_name 冗余不改写；绑定不强制、未绑定零影响）

§6.1 审核条目状态机 · bd_pending_entries.status
pending ──通过新增(create)──▶ created 写入字典 + 来源同步回填 + 引用异步回填
pending ──合并现有(merge)──▶ merged 改指现有目标，字典无新增
pending ──驳回(reject)─────▶ rejected 录入端当场改选改指；机器/C 端转运营待办
终态不可逆；resolve 行锁，并发重复审核 409（FR-19）；merge/reject 必须携带目标 id（录入端，BR-10/27）
§6.2 业务单据字典关联 · dict_status（v1.9 增 rejected：projects / leads / l4_marketing_projects / properties）
manual ──关联/转正──▶ linked　manual/linked ──提交新增──▶ pending
pending ──created/merge/reject(改选)──▶ linked（标签摘除）　pending ──reject(机器/C 端)──▶ rejected
rejected ──人工绑定(FR-12)──▶ linked　linked ──解除──▶ manual　标签一律由状态计算，禁止拼名称
