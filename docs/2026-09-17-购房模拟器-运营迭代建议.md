# 购房模拟器 · 运营迭代建议

> 撰写日期：2026-09-17
> 角色视角：产品运营负责人
> 前提：产品流程已跑通（judge：流程无阻塞），此文只谈「运营逻辑与增长」
> 核心目标：用户完成模拟后，**愿意主动分享给家人和朋友**，让产品从「用完即走」变成「自我造血」

## 一、现状诊断：为什么现在「用完就关」

代码事实梳理（`miniapp/pages/house-simulator`）：

| 维度 | 现状 | 后果 |
|---|---|---|
| 结尾出口 | [scenes-close.ts#L152](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/scenes-close.ts#L152) `sceneFinal` 唯一主按钮是「重来一次 · 换一条路」，无分享、无保存、无结果沉淀 | 情绪峰值（"交房了 🎉"）出现即熄火，峰值被浪费 |
| 分享能力 | 全目录 0 处 `onShareAppMessage` / `onShareTimeline` / 分享按钮（grep 无命中） | 用户想晒都没有出口 |
| 结果资产 | 总账屏已有「该掏的 → 实际掏的」「经历周期 → 常规周期」「学费清单」等强对比数据 | 数据本身是天然传播素材，但只存在于屏幕，无法带走 |
| 复玩钩子 | 只有「重来一次」，无成就、无历史、无排行 | 二刷无动力，复访无入口 |
| 归因 | 无带参分享，无法统计「谁带来谁」 | 增长不可衡量，运营无法投入 |

**根因**：产品当前停留在「单机体验工具」，缺的不是好内容，而是「把结果变成社交货币」的最后一公里。用户花了 10 分钟换回一串数字，却没得到「一张可以晒的牌」。

往期产品调研与分享归因基建已有（`miniapp/pages/about`、`valuation/submit`、`recruit/detail` 等的 `onShareAppMessage`/`onShareTimeline`/`open-type="share"`/海报保存/同步归因均已实现），**房屋模拟器只需接入既有模式，无需重建基建**。

## 二、平台与用户调研要点（小红书等社媒）

### 2.1 小红书房产内容正处于高增长窗口

- 2024 年小红书站内**房产兴趣人群超 8000 万**，买房相关搜索热度日均同比增长 45.8%；「上海 2024 新房」词条年搜索量 1443 万+，同比 +144.4%。
- 用户决策链路：「信息流种草（40%）→ 主动搜索（60%）→ 多篇对比 → 私信咨询」，购房者**平均阅读 18 篇笔记、对比最多 23 个项目、决策周期 30-90 天**。
- 人群画像：95 后/00 后占比过半，一二线 50%；**房产相关用户 71.3% 是女性**，「女生买房」「婚前买房注意事项」「30 岁前买第一套房」（单篇最高点赞 13.6 万）是年度热搜。
- 启示：购房类内容不缺流量，缺的是「可参与的互动形态」。模拟器天然是「测评实验类」内容（小红书家居家装行业白皮书：**测评实验类内容信任度最高**），从「看攻略」到「亲自模拟一把」是一步极低门槛的跨越。

### 2.2 测试/模拟类爆款的传播方法论（可复用的四要素）

复盘网易云「人格测试」「主导色」、MBTI 小程序、小红书「女巫的毒药」等案例，能刷屏的测试类产品都做对了四件事：

1. **社交货币（优越感）**：结果必须让我「看起来更好」——夸我、给我好称号、给我稀有标签。「结果基本都是好的」是设计，不是巧合。
2. **稀有度**：「你比 98% 的玩家更会砍价」「极少数人走完 0 坑路线」——稀缺感逼出分享欲。
3. **准确度（说到心坎里）**：结果要具体到我的选择上（我选了哪套、砍了多少、卡在哪一天），泛泛而谈无法打动我发给家人。
4. **场景化与仪式感**：沉浸式对话（本项目已具备）、结果页的仪式感（本项目"交房了 🎉"已具备）。

### 2.3 微信生态的种子裂变机制（已被验证的落地玩法）

- **带参分享 + 归因漏斗**：(miniapp 已有基建) 在 `onShareAppMessage`/`onShareTimeline` 的 path/query 塞 `inviter` 参数，接收方 onLoad 解析落库，形成可统计的拉新链路。
- **结果海报**：一键生成带小程序码的专属海报，支持保存相册/转发，是测试类小程序的标准裂变载体（MBTI/人格类小程序标配）。
- **PK 与排行**：好友间「契合度对比」「排行榜」驱动二次传播；「女巫的毒药」证明「互坑/互动」比「单机晒图」更强——渗透好友、闺蜜、情侣、家庭多类场景。
- **邀请激励**：邀请 N 人解锁进阶权益/称号（阶梯奖励），将「晒图」升级为「拉新」。
- **情感化文案卡片点击率高 3.2 倍**；分享入口放在「情绪高潮位」转化率显著更高。

### 2.4 产品属性决定分享动机：工具向 ≠ 人格向（本次方案的第一原则）

模拟器是「工具向」，不是「人格测试向」，两者的分享机制完全不同：

| | 人格测试（MBTI/网易云） | 购房模拟器（工具向） |
|---|---|---|
| 分享动机 | **ego 驱动**：展示自我、标榜标签 | **value 驱动**：帮到正在看房/装修的人、让家人放心 |
| 海报核心 | 性格词、稀有标签、夸夸文案 | **费用清单 + 流程图 + 避坑清单**（实用三件套） |
| 最可能转给谁 | 广泛好友 | 正在考虑买房的人、家人、朋友中的买房话题群 |
| 结果的生命周期 | 看完即弃 | 真买房时可反复回查的「可带走文档」 |
| 最有效话术 | "你是稀有物种" | "这套流程值得你走一遍" |

**推论**：本方案所有分享承载，必须坚持「接收方能带走、能用上」优先于「分享方自我展示」——海报的美学与炫耀性是加分项，但实用性才是触发转发与保存的真实原因。

## 三、运营策略总览

一句话定位：**把 10 分钟的模拟，兑换成一张「可以发给家人看的成绩单」和一场「可以和朋友比的较量」。**

三条主线（对应三波用户分层）：

| 主线 | 场景 | 面向 | 北极星抓手 |
|---|---|---|---|
| A. 结果即工具卡 | 单局完成 → 生成「费用清单+流程图+避坑清单」三栏结果卡 + 称号 | 本人（带走纪念）+ 接收方（可复用） | 完成→分享率 |
| B. 接力给家人 | 完成 → 传给爸妈/另一半接着玩 → 家庭对比 | 家人（共同话题） | 完成→邀请家人率 |
| C. 比给朋友 | 好友 PK/排行榜 → 谁更精打细算 | 朋友（较量/互坑） | 完成→PK 参与率 |

## 四、迭代方案（按优先级）

### P0-1 结果工具卡：三栏结构 —— 费用清单 · 流程图 · 避坑清单

**改动位置**：`scenes-close.ts` `sceneFinal` 结尾屏。

把「交房了 🎉」的成果，沉淀成一张「**能带走、能用上、愿意转发**」的结果卡。核心设计原则对齐 §2.4：**接收方能带走什么，比分享方看起来多厉害更重要**。三栏正好对应产品的三个核心问题，数据全部复用现有口径（避免两套口径）：

| 栏目 | 回答的问题 | 数据结构（直接复用） |
|---|---|---|
| 费用清单 | 大概花多少钱 | [scenes-close.ts#L169-L174](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/scenes-close.ts#L169-L174) pricebar「该掏的 → 实际掏的」+ `money()` 税费/中介/装修逐行明细 |
| 流程图 | 需要多长时间 | [scenes-close.ts#L186-L193](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/scenes-close.ts#L186-L193) gantt「经历周期 vs 常规周期」+ 12 节点横轴各段耗时 |
| 避坑清单 | 如何避坑 | `lossRows()` 多花明细 + `riskLog` 风险记录 + SIGN_ITEMS/HAND_ITEMS「写清这 N 项」 |

1. **双版本输出**

   - **一眼版（5:4 分享卡）**：主标题 + 三栏各一行核心数字 + 称号 + 小程序码（带 `inviter` 参数）——职责是「让人愿意点进来」，强制留白、数字放大。
   - **详情版（1:1 长图，保存相册）**：完整费用明细逐行 + 节点流程 + 完整避坑清单——职责是「让人保存下来」，真买房/装修时可回查。
   - 主按钮从「重来一次」改为「**生成我的结果卡**」；次操作：保存详情版 / 分享一眼版 / 重来一次 / 开始装修。

2. **称号体系（数字为主，称号为辅；夸夸式保证正反馈）**

   - 称号与「做到了什么」强绑定、摘自结果数字，而非性格标签：
     - 0 坑通关 →「避坑满分业主」
     - 多花 ≤5 万 →「省钱精算师」
     - 未超常规周期 →「节奏大师」
     - 掉坑交了学费 →「学费已交 · 下次必赚」（调侃式正向，兼埋二刷钩子）
   - 稀有标签按身份/环线/自定义房源出，如「全上海独一份的 1600 万选手」。
   - **原则：称号全是正向或"调侃式正向"，杜绝羞辱**。分享欲来自优越感不错，但工具向用户的首要满足感来自数字（"我真的只多花了 3 万 / 0 坑通关"），称号只是调味。

3. **分享承载（利他标题优先）**

   - 微信好友卡片：`onShareAppMessage` 标题做 A/B —— **利他版**「上海买房避坑清单｜选房→交房全流程费用实测」 vs **利己版**「我在模拟器买房只多花了 ¥3 万，你能比我省钱吗」，path 带 `inviter` 归因，`imageUrl` 传一眼版。
   - 朋友圈：`onShareTimeline`（1:1 详情版 + 「交房了 🎉 我把费用 / 工期 / 避坑全算了一遍」）。
   - 按钮：`open-type="share"`（聊天）+ 保存相册（详情版可被二次转发，进入"可用资料"链路）。

**验证点**：「生成结果卡」点击率 ≥60%；分享率（分享/生成）≥30%；详情版保存率 ≥15%。

### P0-2 分享入口前置：在情绪高潮位埋「轻分享」

总账屏是唯一出口太晚。在流程中的高情绪节点插入轻量分享（卡片式，不打断主流程）：

- **选房完成**（`sceneSelect` 之后）：icon 右上角「把我的这套房发给 TA」——空中介对话 → 微信卡片「看，我刚选的这套，你猜多少钱」。
- **砍价成功**（`scenes-nego.ts` 三轮砍价落地）：「砍到 ¥xx 万，战果如何？」卡片。
- **签约 10 分钟**（`signNet`/`sceneSign` 坑位屏）：「签字前先看这 10 分钟，避坑清单发你」。

理由：这是「女巫的毒药」式**场景化内容**——每个节点都是一句话能说清、能引出互动的牌。分享发生在「正在进行时」，比完成后分享更有参与感。

**验证点**：中途分享点击率 ≥10%，且带来的新用户完成率不低于老用户（内容不过量）。

### P1-1 接力给家人：「把模拟器带回饭桌」（核心增长场景）

**洞察**：买房是中国家庭最大的共同决策。用户完成后的真实场景是——"妈，我今天模拟买了一套房"。**把「晒」升级为「一起玩」**：

- 完成页新增「**喊爸妈/另一半一起玩**」：转发一条带 `inviter` 的邀请卡片（标题如「妈，来帮我把把关——你已经帮我看了 3 次房了」）。
- 家庭模式（低成本版）：家人玩完后，回到本机查看「**家庭对比**」——各自选的房/预算/多花金额的横向对比 + 一句「你比我省的 ¥xx 万，够充十年电费」式互动文案。
- 身份设定延伸：现有 `ROLES` 身份（首套/置换/投资等）本身可承载「家长视角」——增加「帮女儿把关」等长辈向口语入口，或复用现有身份即可，先用文案把"这是家庭话题"立起来。

**理由**：调研明确「渗透家庭场景」是女巫的毒药式产品破圈的关键（家庭/情侣/闺蜜多类人群）。家人是**相关性最高的转发对象**——买房从来不是一个人的事。

**验证点**：完成用户的「喊家人一起玩」点击率 ≥15%；被邀请人完成率 ≥30%（即时流约 17:00-22:00 家庭场景投放）。

### P1-2 朋友较劲：PK 排行榜与「谁更会过日子」

- **好友 PK**：完成页「和 TA 比一比」→ 生成一张「双人对比卡」（各自多花金额/称号并列），邀请好友时带入对方已保存的结果。
- **排行榜（轻量版）**：本机 Top10 + 邀请吸引，「谁 0 坑通关」「谁砍价最狠」。
- **邀请解锁**：邀请 1 位解锁「稀有称号库」，3 位解锁「第二套房剧本」（P2 内容），用阶梯奖励闭环拉新（参考拼多多/瑞幸已验证的机制）。

**验证点**：PK 生成率 ≥20%；邀请转化率（新用户/受邀卡片）≥15%。

### P1-3 复玩钩子：让用户「明天还想来」

- **历史记录**：本地 `wx.setStorageSync` 复数局成绩（沿用 MBTI 小程序本地历史模式），对比「上局 vs 本局」，右上角入口。
- **成就体系（轻量）**：全身份通关 / 0 坑通关 / 满五唯一选手 / 自定义房源挑战者 等徽章，徽章不满 → 促复玩。
- **每日一房**：每天给一套限定挂牌价的房源「你会怎么买？」——低成本日更内容，制造固定回访理由（给运营做话题的基础设施）。

### P2 小红书等内容矩阵（放大声量，反哺小程序）

1. **官方话题**：#我的购房模拟成绩单，成绩单海报天然带话题切口，用户晒单即种草。
2. **晒单激励**：每月按「多花金额最少/最有梗/最精致」抽奖（低成本），激励 UGC 笔记（文案、构图、教程类均可）。
3. **KOS/测评笔记**：结合「女生买房」「婚前买房」「30 岁前买第一套房」等热搜词（13.6 万赞的选题路线），由素人账号发「买房避坑模拟器测评」日记；小红书评测实验类内容信任度最高，天然适配。
4. **攻略内容输出**：把模拟器里的「签字 10 分钟」「交房 4 项核对」等内容落成小红书图文攻略，文末引体验入口（内容 → 体验 → 晒单 → 内容，形成闭环）。
5. **节日热点**：金九银十、年末「年度买房总结」蹭节点出限定称号/剧本。

## 五、数据指标体系

**北极星指标**：完成用户分享率（完成 12 节点并分享 / 完成用户）。

关键漏斗埋点（复用 miniapp 既有归因能力）：

| 指标 | 定义 | 目标基线 |
|---|---|---|
| 完成率 | 走到 `sceneFinal` / 进入 | 现状先测，目标 ≥40% |
| 结果卡点击率 | 点「生成我的结果卡」/ 完成 | ≥60% |
| 分享率 | 任一分享动作 / 完成 | ≥30% |
| 详情版保存率 | 保存详情版长图 / 完成 | ≥15% |
| 邀请家人率 | 点「喊家人」/ 完成 | ≥15% |
| PK 参与率 | 生成 PK 卡 / 完成 | ≥20% |
| 分享转化率 | 被邀请进入 + 完成 / 分享卡片曝光 | ≥15% |
| 邀请人拉新 | 带 `inviter` 参数的新完成用户 | 月度 ≥1000 |
| 二刷率 | 本机历史≥2 局 | ≥20% |

埋点位置：`onShareAppMessage`/`onShareTimeline`/结果卡生成/详情版保存/称号生成处，均打点「从哪个屏、哪种动作」。A/B：分享卡片利他版 vs 利己版标题分桶并对照转化。

## 七、风险与合规

1. **规避诱导分享**：微信对「诱导分享/诱导关注」红线明确（网易 H5 曾因此被禁）。我们的机制全部是「结果自然值得分享」：称号/结果卡/家庭对比都是体验产物，非「分享才给奖励」。**邀请解锁只解锁「内容」（新剧本/称号），不设强制分享卡点**，避免触碰红线。
2. **微信生态外引流合规**：小红书笔记不得直接放外链/二维码到微信（平台规则），用「搜索关键词」+「品牌号主页」引导，笔记正文引导用语自审。
3. **房产口径合规**：模拟器结果是「演示口径」（现有 `sceneFinal` 已标注「演示口径 · 以官方为准」，沿用），任何对外内容携带同款免责声明，避免税务/贷款承诺。
4. **隐私**：家庭对比/排行仅存本机或仅展示昵称，不采集真实家庭关系数据（最小化原则）。
