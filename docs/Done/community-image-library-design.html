Spec · add-community-image-library

小区户型图库管理模块
高保真设计稿

为 admin 端新增小区维度户型图库，整条链路只处理户型图（其他图片不下载、不保存）。推送房源时用与 admin/properties 相同的 getFloorPlan 逻辑自动选出户型图并归类，运营可手动上传管理，创建线索时按小区选择户型图。设计严格遵循 Steep 设计系统：编辑式 serif 标题（Signifier）+ 工作型 sans 正文（Sohne），单色 Ink 主色 + Apricot/Sky Wash 数据色，24px 卡片圆角 + pill 形主按钮。

路由： /admin/communities/images 权限： property:read / property:write 户型图识别： backend/utils/floor_plan.py（移植自前端 getFloorPlan） 关联 Spec： harden-image-pipeline · add-image-thumbnail · build-miniapp-properties-list 设计系统： Steep（参见 DESIGN.md）

01 · 户型图库列表页

Primary Screen

页面左侧沿用全局侧边栏，右侧主体区由「页面标题 + 上传 CTA」「小区搜索框 + 来源筛选 + 计数」工具栏与「户型图网格 + 分页」三段构成。小区搜索为输入框模式（非下拉），支持小区名与商圈关键词模糊匹配，复用 CommunitySelect 组件。每张户型图卡片悬浮显示预览/编辑/删除操作，左上角来源标签区分抓取（Apricot Wash）/ 上传（Sky Wash）。整个页面只展示户型图，不展示室内图/外观图。

07 · 交互与状态规范

Spec

以下规范在实现时须严格遵循，与 spec.md 中的 Scenario 一一对应。

权限控制

  • 读权限 property:read：可访问列表页、查看户型图、打开预览
  • 写权限 property:write：上传、编辑描述、软删除
  • 无写权限时：隐藏上传按钮与卡片悬浮操作（预览保留）
  • 侧栏菜单按 property:read 过滤显示
  • API 403 时前端 toast 提示「无权限」

小区搜索

  • 搜索式而非下拉（小区数量多）
  • 单一输入框，关键词同时匹配小区名与商圈
  • 复用 CommunitySelect 组件，onSearch 传入自定义查询
  • 后端 GET /properties/communities/search 扩展 business_circle 参数
  • 前端 searchCommunitiesAction 把关键词同时传 q 与 business_circle
  • 结果项显示小区名 + 行政区 · 商圈
  • debounce 300ms，无结果时显示空提示

户型图卡片

  • 缩略图回退：thumbnail_url 为空时使用 url
  • 来源标签：scraped 用 Apricot Wash，uploaded 用 Sky Wash
  • 描述为空时显示斜体占位「暂无描述，点击编辑添加」
  • 悬浮显示预览/编辑/删除三个圆形操作按钮
  • 卡片整体可点击，触发预览 Dialog

上传流程

  • 支持拖拽与点击选择，多选
  • 逐张上传，每张独立显示进度条
  • 失败项保留并标红，可单独移除后重试
  • 全部完成（含失败）后刷新户型图网格
  • 统一描述可空，留空则单张描述为空
  • 上传中「全部上传」按钮禁用

预览 Dialog

  • 左右翻页：键盘 ← / → 同步支持
  • 描述编辑后点击「保存描述」单独提交 PATCH
  • 删除采用内联二次确认，禁用 alert/confirm
  • 软删除后户型图从网格消失，可由管理员恢复
  • 来源房源 ID 可点击跳转至房源详情

线索选择器

  • 未选小区时按钮禁用 + 提示「请先选择小区」
  • 多选交互：点击切换选中状态，边框 + 勾选
  • 已选户型图在底部 strip 显示，可单独移除
  • 确认时追加到 images 字段，不覆盖已有
  • 已在线索 images 中的户型图在选择器中标记「已添加」

响应式

  • 桌面 ≥1024px：网格 4 列，侧边栏常驻
  • 平板 768-1023px：网格 3 列，侧边栏可折叠
  • 移动 <768px：网格 2 列，侧边栏隐藏（移动 Tab Bar）
  • 预览 Dialog 在移动端切换为单栏（大图在上、信息在下）
  • 移动端工具栏元素垂直堆叠

08 · 数据流与 API 映射

Integration

每个界面元素与后端 API 端点的对应关系，方便实现时对照。所有 admin 端点使用 cookie 鉴权 + X-Requested-With 头部。

界面 操作 HTTP 端点 权限
列表页 按小区查询户型图 GET /admin/communities/{community_id}/images property:read
上传 Dialog 上传户型图（multipart） POST /admin/communities/{community_id}/images property:write
预览 Dialog 更新描述 PATCH /admin/community-images/{id} property:write
预览 Dialog 软删除户型图 DELETE /admin/community-images/{id} property:write
线索选择器 查询线索关联小区户型图 GET /leads/{lead_id}/community-images lead:read
线索选择器（创建时） 无 lead_id 时回退到 admin 端点 GET /admin/communities/{community_id}/images property:read
