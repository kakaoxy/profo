### 2.2 issue 未提的三个关键发现

| # | 发现 | 证据 | 影响 |
|---|------|------|------|
| F1 | **`api-client.ts` 靠 `window.location.pathname` 嗅探 refresh endpoint / 登录路径**（`startsWith("/admin")`） | `api-client.ts` L8-12、L66-75 | **组件中立性已被破坏**：C 端页面一旦复用任何引用 `api-client` 的组件（如 `dict-address-picker`、`dict-link-card` 均引用 `client`），401 时会走错刷新端点/跳错登录页——这就是 issue 说的「只在某个入口出现的隐蔽 bug」的结构性根源。**本专项最高优先消除点** |
| F2 | 存在**第三份** 401 刷新逻辑 | `lib/swr.ts` `fetcher()`（C 端 + admin 共用，自带 refreshTokensDedup + retryable + AuthError 分流，与两个 client 平行） | 合并范围 = 3 份，不是 issue 说的 2 份 |
| F3 | 服务端两套 401 处理**语义真实不同** | `api-server.ts`：区分 Server Action（内存刷新重试）/ Server Component（`redirect("/api/auth/refresh?next=…")` 落盘 cookie，涉 NEXT_REDIRECT 守卫链）；`api-c/server.ts`：Server Action 内简单删 cookie 重刷重试 | 合并时**必须保留语义差异**（admin RSC 的 redirect 链是 401 自动恢复的关键，不能被「统一」掉） |

### 2.3 验证判定

**议题二成立**，改造对象为「**3 份浏览器端 401 逻辑 + 2 份服务端 fetch 封装**」，方案 = 一套工厂 + 显式身份配置（消灭 F1 路径嗅探），渐进替换。双 adapter（auth.ts/admin-auth.ts）**保留**——强制改密头、role 字段、me 结构差异真实，强行合并参数面爆炸、收益为负（见 D8）。

## 3. 专项一（P1）：业务配置化

### 3.1 已决口径（实施中不得自行偏离）

| # | 口径 | 理由 |

| D2 | 字典范围（本期 4 组）：`lead_attr_channel`（线索归因渠道）、`recruit_source`（招募来源，种子含 card/poster）、`document_template`（文书模板，按 business_form 分组）、`renovation_stage_alias`（改造阶段显示别名） | 对应 V4/V5/V7 与 issue 场景 A/B/C；`lead.source`、`GrowthModule`、`PropertyStatus`、`BusinessForm` 均不入（D3/D4） |
| D3 | `GrowthModule` / `lead.source` / `PropertyStatus` / `BusinessForm` **不配置化** | 它们是系统行为路由/数据契约，不是运营可变的展示字典；配置化反而制造事故面 |

| D8 | （属于专项二，提前对齐）双 adapter 保留，只合并请求层 | 见 §2.3 |

### 3.2 数据模型（迁移 `v_next`，幂等）

```python
# backend/models/system/biz_dict.py
class BizDictItem(BaseModel):
    __tablename__ = "biz_dict_items"
    dict_code: Mapped[str]        # String(50)，字典组：lead_attr_channel / recruit_source / ...
    code: Mapped[str]             # String(50)，组内唯一，存量枚举值原样迁移（card/poster/...）
    label: Mapped[str]            # String(100)，展示名
    business_form: Mapped[str|None]  # String(20)，仅 document_template 用（agent/wholesale）
    sort_order: Mapped[int]
    enabled: Mapped[bool]         # 停用不删（D6）
    is_builtin: Mapped[bool]      # 种子预置；与 FinanceSubject.system 同语义
    remark: Mapped[str|None]
    __table_args__ = (
        Index("uq_biz_dict_items", "dict_code", "code", unique=True),
        Index("idx_biz_dict_items_dict", "dict_code", "enabled", "sort_order"),
    )
```

种子数据（幂等 upsert，`ON CONFLICT DO NOTHING` 语义）：`recruit_source` ← `RecruitLeadSource`（card/poster）；`document_template` ← `constants/documents.py` 全量 30 项（携带 business_form/display_order/category）；`lead_attr_channel` ← 存量 `share_tracking.source` / visit source 的 distinct 值盘点 + 运营补充（实施时先跑盘点 SQL 定种）；`renovation_stage_alias` ← `RenovationStage` 7 值。

**常量回退**：`constants/documents.py` 保留为代码默认（字典缺行/损坏时回退），与 `subscribe_templates` 的 env 兜底同构——读取路径永远可用。
