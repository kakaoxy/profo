设计决策与规范落地

字体发声权 · Signifier 独占标题

所有 section 标题与 Hero 主标用 Source Serif Pro / Noto Serif SC 衬线（Signifier 替代），正文与 UI 一律 Sohne（Inter 替代）。Signifier 永不低于 24px，守住"编辑感发声"的规范底线。

单主按钮 · Ink 唯一填充

全页仅 1 个 Ink 填充主 CTA「立即报名」，次操作用白底描边或文字链。成功页的「返回首页」做反白处理，避免出现两个实色按钮争夺注意力。

橙色标签 · Apricot Wash 替代饱和橙

用户原文「橙色标签底纹」按 Steep「禁饱和色」铁律，落地为 Apricot Wash #fbe1d1 底 + Rust #5d2a1a 字。Hero 三个标签与痛点暖卡同源，形成暖色脉络。

评价卡 · Sky Wash 冷色平衡

两条评价用 Sky Wash #d3e3fc 底色，与暖色痛点卡形成冷暖节奏。五星评分用 Rust 描边，引号用 Signifier 衬线放大——口碑区的"编辑感"由此而来。

圆角系统 · 24 / 16 / 9999 三档

所有内容卡 24px、输入框 16px、按钮与标签 9999px 胶囊。流程节点用 32px 圆形序号，头像 9999px。无任何低于 12px 的锐角，保持"陶瓷片"质感。

阴影三段栈 · 卡片浮起语言

数据卡、表单卡用 --shadow-card（1px ink 边 + 20px/25px 主投影 + 8px/10px 微投影）三段栈浮起；痛点小卡降级为 --shadow-sm 单段投影，形成主次层级。

Hero 径向光晕 · 仅此一处

顶部 Apricot 径向渐变光晕严格限定在 Hero 区，product UI 区域保持纯白 / Fog 背景。成功页徽标用 Apricot 实色圆而非渐变，守住"暖色光晕不外溢"规范。

留资最简 · 仅商圈 + 协议

表单只保留「所在商圈」+「隐私协议」两项，符合"配置化表单尽量精简"的项目约定。手机号走既有 phone-bind-modal 组件授权，不在本页重复采集。
