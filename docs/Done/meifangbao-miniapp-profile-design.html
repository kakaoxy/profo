交互要点与下一步

  • 条件显隐：「内部入口」分组仅当用户权限身份为内部员工时渲染；普通用户只显示「我的估价」。
  • 身份来源：由后台扫码绑定微信后下发权限身份，前端据此控制内部入口可见性。
  • 用户基础信息：昵称 / 用户名 / 手机号（脱敏）/ 权限身份。
  • 手机号完善：未填写手机号的用户，手机号位置显示「完善手机号」；点击后切换为输入框，填写（≥5 位）确认后脱敏更新展示（如 138****5678）。
  • 下一步建议：本稿为高保真设计稿，可作为 miniapp/pages/profile/index 真实页面实现的视觉基准（wxml / wxss / ts）。
