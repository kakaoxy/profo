📊 两种业务模式 · 核心对比
代理赚取差价分成，收购赚取买卖差额——两种模式现金流结构完全不同
🔵 代理业务（差价分成模式）
📐 核心逻辑 公司与业主约定底价 → 公司投入装修/营销 → 卖出后业主收款 → 业主将高出底价的部分（差价）支付给公司
公司不触碰房屋全款——买方资金由业主收取
① 收入 = 增值服务费（记账与合同的正式科目名）= 卖出价 − 业主底价
公司承担：装修费、营销费、运营服务费、差额税费（含差价×1%售房佣金+个税）
产权不发生转移，始终在业主名下
🟣 收购业务（买卖差额模式）
📐 核心逻辑 公司让个人代为买进房产（产权登记在代买人名下）→ 与个人签署代理美化协议做合规耦合 → 持有期还月供 → 翻新后卖出 → 售房差额 = 卖出价 − 买进总成本（佣金在毛利层扣减）
产权登记在代买人（个人）名下——公司不直接持有产权，通过内部代理美化协议约束
① 收入 = 售房差额——卖出价 − 买入总成本（含原始贷款、月供利息）
② 毛利 = 售房差额 − 购房佣金 − 售房佣金 − 装修类（佣金统一在毛利层扣减）
月供利息含于"售房差额"公式；项目分润归为融资成本；投资款本金往来不进损益
公司承担代理中本应由业主承担的卖方税费（代持个人可看作代理中的业主）

📐 关键公式 · 利润计算逻辑
🔵 代理业务
① 收入：增值服务费 = 卖出价 − 业主底价
（记账与合同的正式科目名，业主收到全款后支付给公司）
② 毛利 = 收入 − 直接成本
+ 增值服务费
− 收房佣金（含线索获取+签约成本）− 装修类（设计/装修/软装）
③ 净利润 = 毛利 − 运营费用 − 融资成本 ± 其他
− 营销类（推广/额外激励/其他）
− 营销推广费 = 卖出价 × 0.5%
− 运营服务费 = 卖出价 × 1%
− 差额税费 = 卖房佣金差额 + 个税
• 卖房佣金差额 = (卖出价 − 业主底价) × 1%
• 个税 = (卖出价 − 业主底价) × 税率（非继承1%/继承20%，仅房东有个税时产生，公司承担差额部分）
− 融资成本（项目分润）
+ 他项收入 − 结算差额
注：投资款本金（收入/还本）为资产负债往来，不进损益；保证金、暂支款配对净额=0
🟣 收购业务（损益口径）
① 收入：售房差额 = 卖出价 − （购房定金+首付+贷款+贷款差额+交易税费+尾款+名额费+月供利息）
（"贷款"为原始总额，月供本金不另列支；月供利息作为取得成本已含于差额公式；购房佣金/售房佣金移至毛利层扣减）
② 毛利 = 收入 − 直接成本
+ 售房差额
− 购房佣金 − 售房佣金 − 装修类（设计/装修）
③ 净利润 = 毛利 − 运营费用 − 融资成本 ± 其他
− 营销类（推广/额外激励/其他）− 营销推广费 − 运营服务费 − 差额税费
• 差额税费含公司承担的卖方税费（代理中本应由业主承担）
− 融资成本（项目分润）
+ 他项收入 − 结算差额
注：投资款本金（收入/还本）、贷款发放/偿还、月供本金、卖房还贷均为资产负债往来，不进损益；暂支款配对净额=0
💡 利润三层结构（权责发生制·损益口径）：① 收入 = 增值服务费/售房差额（取得成本已内化）；② 毛利 = 收入 − 直接成本（佣金 + 装修类，收购含购房佣金+售房佣金）；③ 净利润 = 毛利 − 运营费用（营销/推广/运营/税费）− 融资成本（分润/利息）± 其他。融资本金往来（投资款收入/还本）不进损益；代理"差额税费"已含售房佣金差额（差价×1%+个税）。
💧 现金流口径（收付实现制·资金追踪）：追踪项目全周期现金进出，与损益口径并行。现金流入 = 贷款发放 + 项目投资款收入（含情况二还贷垫付）+ 收卖房定金/首付/尾款；现金流出 = 6项取得成本 + 购房佣金 + 月供本金 + 月供利息 + 卖房还贷（仅情况二，投资款垫付）+ 装修/营销/运营/税费 + 投资款还本 + 项目分润。净利润 ≠ 净现金流，差异项为贷款往来、月供本金、卖房还贷、投资款往来、卖房收款时序（详见 SECTION 6.5）。

流出：6项取得成本 + 购房佣金 + 月供本金 + 月供利息 + 卖房还贷（仅情况二）+ 装修/营销/运营/税费 + 投资款还本 + 项目分润
关键差异项：贷款往来、月供本金、卖房还贷、投资款往来、卖房收款时序
📌 两表关系：净利润（损益表）≠ 净现金流（现金流量表）。差异来源于资产负债项的现金往来（贷款、投资款、垫付款）以及卖房收款的时序分布。两表独立编制，互不干扰，共同完整描述项目财务状况。
⚠️ 情况二（需还贷）资金闭环：投资款垫付（流入）→ 卖房还贷（流出）→ 收卖房尾款（流入）→ 归还垫付投资款（流出）。利润与情况一相同，但现金流时序复杂，需投资款垫付还贷资金。

✅ 关键要点总结
🔵 代理收入

增值服务费 = 卖出价 − 业主底价
（记账与合同的正式科目名）

🟣 收购收入

售房差额 = 卖出价 − 买进总成本（含原始贷款、月供利息）
购房佣金/售房佣金在毛利层扣减；产权登记在代买人名下

📊 利润三层

① 收入 = 增值服务费/售房差额
② 毛利 = 收入 − 佣金 − 装修类
③ 净利润 = 毛利 − 运营费用 − 融资成本 ± 其他

📆 贷款与利息处理

月供 = 本金 + 利息
月供利息已含于售房差额公式（损益口径）
月供本金为现金流科目（资产负债项，不进损益，单独记录）
首付资金机会成本在跟投逻辑中计算；投资款本金往来不进损益

🏠 卖房两种情况

情况一（不需还贷）：收定金→收首付→过户→收尾款
情况二（需还贷）：收首付→投资款垫付→卖房还贷→过户→收尾款→归还垫付
利润相同，现金流时序不同；项目需标记类型

💧 现金流新增科目

月供本金（持有期·资产负债项）
卖房还贷（已售·仅情况二·投资款垫付）
收卖房定金/首付/尾款（已售·分节点收款）
贷款发放流入（买入·资产负债项）

💰 税费承担

代理：公司承担差额部分税费（卖房佣金差额+个税）
收购：公司承担卖方税费（代持个人=代理中的业主）
个税：差价×税率（非继承1%/继承20%，仅房东有个税时）

⇄ 配对核销

履约保证金 ⇄ 业主保证金回退
暂支款 ⇄ 暂支款核销
净额均应为零

💰 融资模式

两种业务通用，按笔记录来源（公司自有 / 外部资金）
签约阶段流入 → 已售阶段流出（本金+分润）
本金往来不进损益，仅分润作为融资成本扣减
情况二卖房时追加投资款垫付还贷资金

⚖️ 双口径体系

损益表（权责发生制）：算利润
现金流量表（收付实现制）：算资金流
净利润 ≠ 净现金流
两表独立编制，互不干扰
