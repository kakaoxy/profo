# 贷款计算器 · 落地 Spec（实施版）

> 撰写日期：2026-10-03 ｜ 状态：**实施依据**
> 视觉真源：`docs/2026-10-02-贷款计算器-高保真设计稿.html`（**v1.3** · 2026-10-03 修订）
> 需求真源：设计稿头部注释确认的四口径 ——
> ① 详情页「基础信息」与「改造过程」之间静态展示首付/月供 +「查看详情」入口；
> ② 默认口径：首套 · 纯商贷 · 首付 15%（政策下限）· 30 年 · LPR(3.5%) − 45bp = 3.05% · 等额本息；
> ③ 计算器页三种贷款方式（商贷/公积金/组合贷），首付比例、LPR、加点、年限、公积金额度、还款方式均可调；
> ④ 纯前端计算，数据依赖详情接口 `total_price/area`，**零后端变更、零新 API**。
> 政策真源：上海购房按揭政策汇总表 20260901 版（5 年期以上 LPR 3.5%，2026-08-20 颁布）。

## 一、定位与范围

### 1.1 一句话定位

C 端项目详情页新增**贷款参考卡**（按默认口径纯前端算出该房源首付/月供，点击跳转），新增独立**贷款计算器页**（三种贷款方式 + 首付/利率/年限/还款方式全联动 + 还款计划明细弹窗 + **砍价弹层调整总价**）。

> v1.3 迁移说明：v1.2 曾把砍价入口放在详情页总价旁，v1.3 ⑥ 改位到**计算器页房源摘要条**——详情页恢复静态挂牌价，贷款卡始终按挂牌价计算，期望价仅在计算器页生效。落地以 v1.3 为准，详情页无砍价逻辑。

### 1.4 关键口径收口

| # | 决策 | 实施口径 |
|---|---|---|
| K1 | 落位与显隐 | 贷款卡插在详情页 `.info-grid` 与「改造过程」`.detail-section` 之间；`total_price` 缺失或 ≤0 时**整卡隐藏**（`loanCard = null`）；金额由前端按 `total_price` 实时计算 |
| K2 | 默认口径 | `LOAN_DEFAULTS = { mode:"comm", downPct:15, years:30, lpr:3.5, bp:-45, fundAmt:100, method:"axi" }`；公积金利率 `FUND_RATE = 2.6` 固定（本期不开放编辑）；详情卡与计算器页共用同一常量，无镜像漂移 |
| K3 | 首付下限联动 | `DOWN_MIN = { comm:15, fund:20, combo:20 }`，上限 80；**tab 切换**时当前首付低于下限自动抬升至下限；快捷档（15/20/30/50%）同样按下限钳制（设计稿未明确，落地收紧，防负值 fill/低于政策下限的展示） |
| K4 | 参数范围 | LPR 2%~6%、步进 0.05；加点 −100~+100bp、步进 5；公积金额度 10~500 万、步进 5、默认 100 万（组合贷取 `min(fundAmt, 贷款总额)`，商贷部分 = 贷款总额 − 公积金部分）；年限 10/15/20/25/30 五档 |
| K5 | 计算公式 | 等额本息 `M = P·r·(1+r)^n / ((1+r)^n − 1)`；等额本金 月还本金 `P/n`、当期利息 `余额×r`、逐月递减 `(P/n)·r`；`r = 年利率/12`、`n = 年限×12`；组合贷两部分按各自利率**逐期推演后按期合并**（pay/pri/int/bal 逐项相加）；总额以「元」精确计算，万元仅作展示 |
| K6 | 展示精度 | 月供/利息/逐期金额四舍五入到**元**（千分位）；万元保留 1 位小数去尾零；利率 `toFixed(2)`；结果卡等额本金模式附「末月 + 每月递减约」行 |
| K7 | 还款计划弹窗 | 点击结果卡「支付利息」打开；**每次打开按当前参数实时推演 360 期**（期次/月供/本金/利息/剩余本金），纯前端生成，不做缓存；关闭即销毁数据（下次重算） |
| K8 | 跳转与传参 | 贷款卡整体可点 → `wx.navigateTo /pages/loan-calculator/index?price=&area=&title=&phone=`（title/phone encodeURIComponent；phone 为分享人/顾问电话，K11）；price 缺失/非法时计算器页展示「未获取到房源总价」错误态（防止直接扫码进入的脏状态） |
| K9 | 视觉令牌 | 对齐 `app.wxss` Steep 变量（ink/fog/apricot-wash/rust/graphite/dove）；rpx 换算按设计稿 390 宽 ×≈1.92；结果卡 ink 深色卡、参数卡白卡、fog 底控件，与详情页 info-item 语言一致 |
| K10 | 砍价（v1.3 ⑥） | 摘要条右下「砍价」apricot 胶囊按钮 → 弹层输入期望总价：① 合法范围 **(0, 9999] 万**，非法输入 toast 且**不关闭弹层**；② 确认后摘要条价格行展示**新价 + 划线原价 + 标签转「期望总价 · 已砍 ¥X万」**，全部结果按期望价重算；③「恢复原价」置回挂牌价；④「恢复默认口径」同时**清除期望价**（设计稿 DEFAULTS 含 customPrice:null）；⑤ 期望价仅本页内存态，**不回写详情页、不持久化**；⑥ 弹层输入框 placeholder 为挂牌原价，再次打开时回填当前期望价 |
| K12 | 自定义首付金额 | 首付快捷档行尾新增「自定义」chip → 弹层手填**首付金额（万元）**：① 有效区间 **[总价×首付下限, 总价×DOWN_MAX]**（与滑杆同口径，如 486 万商贷 = [72.9, 388.8] 万）；② 低于下限 toast 提示含下限金额；高于上限 toast 提示含上限金额；均**不关闭弹层**；③ 合法金额换算为首付比例**保留 9 位小数全精度**（toFixed(9) 兼清洗浮点尾差，不做取整——2026-10-03 修订：取整导致手填 80 万被改为 79.4 万的偏差，违背「手填金额即所得」业务实操）+ `clampDownPct` 钳制；④ 换算比例落在 15/20/30/50 快捷档时对应 chip 高亮，否则仅滑杆近似定位（无 chip 高亮属预期态）；⑤ 比例展示最多 2 位小数去尾零（`fmtPct2`，内部计算仍用全精度值）；⑥ 弹层打开时回填当前首付金额（期望价口径），placeholder 为下限金额；⑦ 弹层复用砍价弹层骨架（标题/文案/单位不同） |
| K11 | 底部行动按钮 | 计算器页底部（恢复默认下方）并排两钮：①「贷款专家咨询」——`wx.makePhoneCall` 拨打**分享人/顾问电话**：详情页已在 `loadDetail` 并行拉取 consultant 接口（`referrer` 命中时后端返回分享人真实手机号），跳转参数追加 `phone`（encodeURIComponent），计算器页缺失时点击 toast「暂未获取到联系方式」，拨号取消静默；②「了解购房流程」——`wx.navigateTo /pages/house-simulator/index/index`（已注册页面）。两钮独立可用，**零新 API** |

### 2.2 `utils/loan-calc.ts` API

```ts
type LoanMode = "comm" | "fund" | "combo";      // 纯商贷 / 纯公积金 / 组合贷
type RepayMethod = "axi" | "prin";              // 等额本息 / 等额本金
interface LoanParams { mode; downPct; years; lpr; bp; fundAmt; method }
interface ScheduleRow { pay; pri; int; bal }     // 均「元」
interface LoanResult { downWan; loanWan; first; last; dec; interestYuan; execRate; commRate; rows: ScheduleRow[] }

calcLoan(priceWan: number, p: LoanParams): LoanResult   // priceWan ≤ 0 → 全零 + rows=[]
clampDownPct(pct: number, mode: LoanMode): number       // max(DOWN_MIN[mode], min(80, pct))
stepLpr(v, dir): number      // ±0.05，钳 2~6，两位小数防浮点尾差
stepBp(v, dir): number       // ±5，钳 −100~+100
stepFundAmt(v, dir): number  // ±5，钳 10~500
fmtWan1(x): string           // 万元 1 位小数去尾零："72.9" / "100"
fmtYuanInt(x): string        // 元四舍五入 + 千分位："17,528"
fmtBp(v): string             // "−45" / "+30" / "0"（U+2212 与设计稿一致）
parseBargainInput(raw): number | null  // 砍价输入解析，合法 (0, BARGAIN_MAX_WAN=9999]，非法 null
```

### 2.3 计算器页数据流

- `onLoad` 解析 `price/area/title` → price 非法（非有限正数）置 `invalid` 态；合法则 `price`（挂牌原价）+ `customPrice`（期望价，null=未砍）入页内状态，`apply()`。
- `apply()`：`calcLoan(期望价 ?? 挂牌价, params)` → 派生全部展示字符串一次性 `setData`（月供/利率/贷款额/利息/首付/摘要条价格行/参数文案/tabs·chips·seg 高亮/卡片显隐字段）。
- 滑杆 `bindchanging`（拖动中）+ `bindchange`（松手）都走 `apply()`；弹窗数据不在 `apply()` 内生成，仅打开时生成（360 行 setData 一次）。
- 砍价弹层：确认时 `parseBargainInput` 校验，非法 toast 不关闭；合法置 `customPrice` → 关闭 → `apply()` 全量重算。
- 明细行展示串 `{no, pay, pri, int, bal}` 全部格式化后再 `setData`（WXML 不做数值运算）。

### 2.4 详情页改动点

- `PageData` 增加 `loanCard: { downPctText; downText; monthText; sumText; rateText } | null`。
- `loadDetail` 成功分支：`total_price > 0` 时按 `LOAN_DEFAULTS` + `calcLoan` 填充，否则置 null。
- 摘要行**同源派生**（2026-10-03 修订，原硬编码 wxml 与常量漂移会自相矛盾）：方式/年限/利率由 `LOAN_DEFAULTS` 与 `r.commRate` 生成 `sumText`/`rateText`，静态标签「首套」「年利率」与提示行「以等额本息估算，实际以银行审批为准」留在 wxml。
- `onLoanCardTap`：`wx.navigateTo`（K8 传参）。

## 三、交互矩阵

| 控件 | 行为 |
|---|---|
| 贷款方式 tab | 切 mode；首付 < 下限则抬升至下限；利率参数卡显隐联动（comm/fund/combo 三选一）；重算 |
| 首付滑杆 / 快捷档 | 改 downPct（快捷档钳下限）；重算；百分比与首付金额实时刷新 |
| 年限 seg | 改 years（10/15/20/25/30）；重算；「N 期」= years×12 |
| 还款方式 seg | axi/prin；结果卡标题切「月供（等额本息）/（等额本金 · 首月）」；prin 显示「末月 + 每月递减约」；说明文案切换；重算 |
| LPR / 加点 stepper | comm 与 combo 卡共享同一 state（两处显示同步）；重算 |
| 公积金额度 stepper | 仅 combo 卡；fundPart = min(fundAmt, loanWan)；重算 |
| 恢复默认 | state 回 `LOAN_DEFAULTS` 并**清除期望价**（对齐设计稿 DEFAULTS.customPrice:null）；重算 |
| 支付利息 | 打开明细弹窗（按当前参数推演 360 期）；遮罩点击 / ✕ 关闭 |
| 砍价按钮 | 打开砍价弹层（placeholder=挂牌价，已砍价时回填当前期望价并显示「恢复原价」） |
| 砍价确认 | `parseBargainInput` 校验：非法 → toast「请输入有效价格」且不关闭；合法 → 置期望价、关闭、全量重算 |
| 恢复原价 | 期望价置 null、关闭弹层、全量重算（摘要条回到挂牌价 + 「房屋总价」） |
| 自定义首付 chip | 打开自定义首付弹层（回填当前首付金额、placeholder=下限金额、显示有效区间文案） |
| 自定义首付确认 | 金额换算比例（全精度 9 位小数）→ 低于下限/高于上限 toast 不关闭；合法 → 置 downPct、关闭、全量重算（K12） |
| 贷款专家咨询 | 有 phone → `wx.makePhoneCall`（取消静默）；无 phone → toast「暂未获取到联系方式」（K11） |
| 了解购房流程 | `wx.navigateTo /pages/house-simulator/index/index` |
| 详情页贷款卡 | 整卡可点 → 跳转计算器页（携带 price/area/title/phone）；详情页自身无砍价逻辑 |

## 四、边界与异常

| 场景 | 行为 |
|---|---|
| 详情 total_price 缺失/0 | 贷款卡整卡隐藏（K1） |
| 计算器直入且 price 非法 | `invalid` 态：「未获取到房源总价，请从房源详情页进入」 |
| 砍价输入非法（空/≤0/>9999/非数字） | toast 且不关闭弹层，期望价保持不变（K10） |
| 砍价后期望价参与组合贷 fundAmt 上限 | fundPart = min(fundAmt, 期望价贷款总额)，与挂牌价口径一致 |
| 无 phone 直入计算器（分享链接缺参） | 「贷款专家咨询」点击 toast，不崩溃；「了解购房流程」不受影响 |
| 自定义首付输入非法（空/非数字/≤0） | toast「请输入有效金额」且不关闭弹层，首付比例保持不变（K12） |
| 自定义首付超出区间 | 低于下限/高于上限分别 toast（含边界金额），不关闭不生效 |
| 自定义比例与砍价/下限联动 | 期望价或 mode 变化 → 有效区间随期望价重算；无独立金额态（金额仅在弹层内换算为比例），与滑杆同一状态源 |
| 组合贷 fundAmt > 贷款总额 | fundPart 取贷款总额、商贷部分 0（该部分不参与推演，rows 仅公积金） |
| 首付 80%（贷款额极小） | 公式稳健（r=0 时 `P/n` 兜底分支保留） |
| tabs 快速切换 / 滑杆高频拖动 | `apply()` 幂等全量派生，无累计态；setData 载荷小（明细不在其中） |
| 利息合计与逐期一致性 | rows 由同一推演生成：Σpri = 贷款额、Σint = interestYuan（测试锚定，±1 元舍入容差） |

## 八、已驳回的审查问题（存档备查）

| 问题 | 驳回理由 |
|---|---|
| 跳转路径缺 `miniapp` 前缀（建议改 `/miniapp/pages/...`） | **不成立**：小程序 `navigateTo` 绝对路径以 `/` 开头、相对 `app.json` 根（即 miniapp/ 目录）解析；`app.json` 注册的就是 `pages/loan-calculator/index`，路径完全正确。全项目 15+ 处 navigateTo 均无 `miniapp` 前缀（详情页自身也以 `/pages/projects/detail/index` 打开，运行中即活证据）。若按建议修改反而因路径未注册导致跳转失败 |
| 组合贷 bal 逐期相加导致余额不为零 | **不成立**：数值验证末期余额为 0（等额本息精确 0 / 等额本金 2.6e-8 浮点尾差），逐期守恒 Δbal=pri 360 期全成立；建议的修正代码反而会破坏守恒。见 2026-10-03 验证记录 |
| MODE_LABEL/METHOD_NAME_LABEL 末尾定义导致运行时错误 | **部分成立**：TDZ 仅作用于模块求值阶段，函数调用时访问无问题；但重复定义属实（utils 已导出同值常量），已改为导入 `MODE_NAME`/`METHOD_NAME`，删除重复 |
| 全局变量存页面状态（params/customPrice） | **部分成立**：「back 卸载重进残留」不成立（onLoad 每次重置），但页面栈多实例共存时模块级变量确会串状态，已迁到实例属性并修 invalid 分支重置缺口。见 2026-10-03 修复记录 |
