R8 口径改造对照：旧「当前工序停滞」= 已进行天数（自上一工序完成日/开工日起）超该工序标准工期 → 新「工序节点逾期」= today > 交房日 + N 天 且该工序无完成记录。里程碑锚点 = 约定交房时间（project_contracts.planned_handover_date）； 为空回退「进入装修阶段」状态日志日；两者皆无 → 该项目里程碑规则静默跳过（沿用 R10 缺字段惯例）。 多节点独立判定：逾期未完成节点各自出一条待办（如拆除长期未完成时，「拆除」与「水电」同时提示）， rule_code 扩展为 R8·工序名 保证卡片内 key 唯一；工序已有完成记录（stage_completed_dates）即视为完成、不再提示。 木瓦 / 油漆 / 交付默认值为占位，随本轮配置化交由业务在弹窗内自行校准。

Artboard 02

弹窗解剖 · 三状态

ARTBOARD 02-A · 弹窗解剖（组件标注）
  1. 1页头：标题「规则配置」+ 副文案（影响范围与生效时机）+ ✕ 关闭；✕ / Esc / 点击面板外均可关闭，同屏仅一个。
  2. 2分组一 · 装修工序里程碑：6 个工序节点逐项配置「交房后 N 天内须完成」；组脚注固定解释优先级升级口径（P1 起、逾期超「升 P0 天数」转 P0）。
  3. 3步进器：− / + 单步调整、数字可直输、单位「天」；范围 1~999，失焦自动收敛；输入聚焦反白 + Ink 描边，与 Steep 控件语言一致。
  4. 4分组二 · 宽限与提醒窗口：R2 基础信息缺失 / R6 / R7 / 升 P0 / R4 / R10 六项非里程碑阈值，每行带一句话口径（灰字），避免管理员误改语义；R2 为本轮新增宽限（现网缺即提示）。
  5. 5分组三 · 基础信息字段集（折叠）：默认收起仅显摘要「N 核心 · M 次要」；展开后 11 个字段逐行三态切换（核心 / 次要 / 忽略），决定 R2 检查范围与 P1/P2 分级。
  6. 6页脚：「恢复默认」（回出厂默认值并标记未保存）·「有未保存改动」锈红点标记 · 取消 / 保存；保存后 toast「下个规则快照生效」。
ARTBOARD 02-B · 三状态（编辑未保存 / 非管理员只读 / 保存成功）
管理员 · 编辑态（有未保存改动）
任一数值变动即出现锈红「有未保存改动」；保存 / 取消前关闭面板不丢提示（下次打开仍为已保存值）。
非管理员 · 只读态
顶部灰条说明权限，步进器与字段三态切换禁用（40% 透明 + 不可点），页脚仅「关闭」；阈值口径全员可见，编辑收敛到管理员。
保存成功
底部 Ink toast「✓ 规则配置已保存 · 下个规则快照生效」，约 2.4s 自动消失；页头「规则快照」时间随后续刷新走表。

本轮确认口径：① 交房日 + N 天里程碑制（规则引擎由停滞制改造）；② 开放全部规则阈值；②a R2 基础信息缺失加签约宽限（默认 7 天）且字段集弹窗内三态可编辑；③ 仅管理员可编辑；④ 显式保存 + 恢复默认。
R2 语义改造：触发 = 签约日期 + 宽限天数已过 且 检查中字段仍有缺失；核心缺 → P1，仅次要缺 → P2，全部齐 → 不提示；签约日期缺失时 R2 静默跳过（由 R1 合同未生效兜底）。⚠️ 现网为「缺即提示」，默认 7 天属行为变化，需业务知悉。
生效语义：保存即写 system_configs，看板每次进入都实时重算，故「下个规则快照」= 下次页面加载 / 刷新；已打开页面不热更（页头快照时间可辨别新旧）。
里程碑锚点：约定交房时间 →（为空）进入装修状态日志日 →（皆无）静默跳过；「未完成」= stage_completed_dates 无该工序记录，已记录即视为完成。
待业务确认：木瓦 / 油漆 / 交付默认值为占位（30/45/60 天），交付前在弹窗内校准即可；里程碑锚点回退策略如需改为「仅约定交房时间」请反馈。
沿用口径：R6 / R7 / R4 / R10 规则逻辑不变仅阈值开放；规则号 R* 仍不出现在业务界面（仅 API 与本稿标注）；弹窗视觉与明细弹窗同族。
