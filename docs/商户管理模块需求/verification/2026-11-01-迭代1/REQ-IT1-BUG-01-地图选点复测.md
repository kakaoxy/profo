## 一、复测步骤（每次改配置后请重跑，结果填入第二节）

1. 微信开发者工具「清缓存 → 清除全部缓存」后重新编译，或真机删除小程序重进（确保重新走一次启动流程）。
2. 用有门店建档权限的账号登录（凭据从环境变量 `TEST_USERNAME` / `TEST_PASSWORD` 取，勿写入本文件）。
3. 进入「门店管理 → 新建门店」，点击「选择位置」。
4. 记录弹窗标题/文案。若是「地图选点失败」弹窗，其 `errMsg` 已被复制到剪贴板，直接粘贴到第二节表格。
5. 交叉验证（关键差分测试）：打开「门店拜访 → 新建拜访」，点击定位。`wx.getLocation` 与 `wx.chooseLocation` 同属「位置信息」隐私 scope，两者表现可用于区分「配置类」与「单接口/工具类」故障。

## 三、按 errMsg 定因与处置

| errMsg 关键词 | 含义 | 处置 |
|---|---|---|
| `privacy` / `privacy permission is not authorized` | 隐私指引未同意，或《用户隐私保护指引》未声明「位置信息」 | 小程序后台 →「设置-服务内容声明-用户隐私保护指引」勾选「位置信息」→ 提交审核通过 → 重进小程序 |
| `auth deny` | 用户曾拒绝位置授权 | 弹窗「去设置」开启 |
| `requiredPrivateInfos` / `not declared` | `app.json` 声明缺失（当前已含 `chooseLocation`，理论不会命中） | 代码侧核对 `miniapp/app.json` |
| `not support` / `system permission` | 平台/系统限制（开发者工具模拟、手机定位总开关关闭） | 真机 + 打开系统定位后复测 |
| `cancel` | 用户主动取消 | 无需处理 |
| 其他 | 未知 | 把剪贴板内容原样附在第二节 |

## 四、通过标准

第二节「正常授权（真机）」一行实际结果与期望一致（地图弹出、选中后地址/经纬度回填），且「用户取消」无错误提示 —— 即判定 REQ-IT1-BUG-01 修复完成。
若仍失败，请把粘贴出的 `errMsg` 原文回填到第二节，再按第三节处置；**在拿到 errMsg 前不应改动其他代码**（避免掩盖真实原因）。
