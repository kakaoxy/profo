## 3. 规格细节

### 3.1 状态徽章
- 位置（四轮迭代 2026-10-28，用户反馈）：位于价格行右侧操作组 `detail-head-actions`，与调价提醒铃铛**水平排列**、垂直居中（组内 `gap: 16rpx`，`flex-shrink: 0`）。价格行结构为 `[detail-price-main：主价格 + 价格口径 chip] —space-between— [状态徽章 + 调价铃铛]`。
- 标签行仅承载 tags：`detail-chips-row` 仅在 `detail.tags.length > 0` 时渲染；状态徽章不再进入标签行，无标签时也不会出现空行。
- 已售/不可订阅态铃铛隐藏时，徽章仍右对齐于价格行。
- 形态：胶囊，`padding: 8rpx 20rpx`，圆角 `9999rpx`，字号 `24rpx/500`。

### 3.2 价格区（M-01 / M-03）
- 主价格 `64rpx/500`，`white-space: nowrap` 禁止折行；「价格待定」用 `40rpx` 修饰类。
- 视口 ≤339px：主价格缩至 `56rpx`。
- `total_price ≤ 0` 且无成交价 → 一律渲染「价格待定」/「待定」，禁止出现「¥ 0 万」「0万/㎡」。

### 3.3 调价提醒图标钮（用户反馈 2026-10-28：胶囊改纯图标）
- 形态：88rpx **正圆**图标钮，铃铛 `40rpx`，无文字；无文字语义由 `aria-label` 补偿（未订阅「开启调价提醒」/已订阅「已开启调价提醒，点击可取消」）。
- 正圆保障（二轮迭代：真机上报椭圆）：同页 share-btn 同款处理——`width/min-width/max-width` + `height/min-height/max-height` 全部锁 88rpx、`border-radius: 50%`、`line-height: 88rpx` + `text-align: center` 居中，**不依赖 flex**（真机上 flex 在 button 上可能失效导致椭圆）；`::after` 边框重置。
- 两态配色（沿用原胶囊两态色词汇，白卡上清晰可辨）：未订阅 = ink 实心底 `#17191c`（axe 语义对比 17.6:1）；已订阅 = apricot-wash 暖底 `#fbe1d1` · rust `#5d2a1a`（9.27:1）。
- 🔔 为 emoji 字形自绘色，CSS color 仅作文本字形回退与无障碍语义兜底。
- 剩余提醒额度不再展示（额度状态以点击后的微信授权/取消确认弹窗为准）。

### 3.4 热区（m-02）
- 调价提醒图标钮、状态页按钮：`88rpx`（44px）方形热区（固定尺寸，跨视口稳定）。

### 3.5 加载 / 空 / 错态（m-03）
- 加载：骨架屏（图集块 + 白卡内价格/标题线 + 2×3 信息格骨架），静态无动效。
- 404：`!` 圆形图标 + 主文案「项目不存在或已下架」+ 副文案 + 「返回列表」按钮（navigateBack，无上级时 reLaunch 列表页）。
- 500：同图标 + 主文案 + 「重试」按钮。
- 状态页动作按钮：ink 实心胶囊 `min-width: 240rpx`。

### 3.6 改造过程横滑（m-04）
- 容器右缘 48rpx 白色渐变遮罩（pointer-events: none）。
- 行尾提示：`共 N 个阶段 · 左右滑动查看`（22rpx · graphite · 右对齐）。

### 3.7 对比度（M-02 / D-01，令牌层）
- `--graphite` 由 `#777b86` 加深至 `#676b76`（fog 底 5.0:1 / 白底 5.3:1），全小程序次要文字受益。
- `--dove` 降级为仅装饰用途（分隔线/箭头），文字一律不用。
- 分享钮遮罩 `rgba(0,0,0,.4→.6)`，白字在最亮图上 ≥4.5:1。

## 4. 明确不做（本稿边界）
- 装修中态不做「开工提醒」（需新订阅模板，另行立项）。
- 已售态不做「看看同小区在售」（列表页无按小区筛选能力）。
- 暗色模式、reduced-motion：小程序未实现，不在本稿范围。
