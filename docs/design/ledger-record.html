屏① 项目选择列表 · 设计说明

交互说明
  • 搜索框：触屏键盘 confirm 触发重查，携带 community_name 重新拉取列表。
  • 项目卡片给出 状态徽章（在售=蓝 sky / 装修中=apricot / 在签=暖色）+ 业务模式弱胶囊（代理/包销，Fog 淡底）。

  • GET /api/v1/projects?community_name=&page=&page_size=
  • 需 project:read 权限，走 admin 令牌通道；403 落在「暂无台账权限」态。

屏② 项目账目清单 · 设计说明

交互说明
  • 汇总卡 apricot 浅底，三列总流入(红)/总流出(绿)/净现金流(正负着色)，数字大字号；辅助行 ROI 12.5% · 持有 86 天。
  • 流水按日期倒序；每条含【日期+科目名（L 层级徽章）】【付款方→收款方 + 备注摘要（缺省 —）】【金额 −流出绿 / +流入红 / 缺省 —】。
  • 带票据显示 缩略图角标（纯色占位 + 张数）；无票据显示弱标签 「缺凭证」（amber）。
  • 底部固定 「记一笔」墨色胶囊大按钮；示例数据覆盖流入/流出/带票据/缺凭证各至少一条。
API / 权限标注
  • GET /api/v1/admin/ledger/{project_id} → 返回 records[] + summary{total_income,total_expense,net_cash_flow,roi,holding_days}
  • 需 ledger:read 权限，走 admin 令牌通道。

屏③ 记一笔 全屏表单 · 设计说明

交互说明
  • 表单自上而下滚动：项目上下文头（只读 + 更换返回）→ 科目分类 → 流出/流入互斥金额 → 付款方/收款方 → 发生日期 picker → 票据九宫格（1 添加格 + 已传缩略图）→ 备注文本域。
  • 金额双列 左绿（流出）/ 右红（流入），带 ¥ 前缀与 0.00 占位；下方灰字互斥规则说明。
  • 底部固定 「确认记账」墨色胶囊大按钮。校验错误态 = 科目与金额行下方红字报错；提交中态 = 按钮变灰 + spinner。
  • 票据添加处 wx.chooseMedia，最多 9 张。
API / 权限标注
  • GET /api/v1/admin/subjects?mode=agent|acquire（需 subject:read，随项目业务模式过滤）
  • POST /api/v1/admin/ledger 提交 LedgerRecordCreate（需 ledger:write）
  • 票据上传 POST /api/v1/files/upload（需 admin 令牌）

屏④ 记一笔 ─ 科目选择 · 设计说明

交互说明
  • 半屏底部弹层：遮罩 rgba(23,25,28,0.4) + 底部圆角面板，叠加于表单页之上。
  • 面板内容：标题「选择科目」→ 搜索框 → 科目按 L1–L7 分组（吸顶组头小标签），需展示 ≥2 个层级分组。
  • 科目行 = 层级徽章(L2) + 名称 + 右侧标签 「进损益」(绿)/「不进损益」(灰)；选中态 = 勾选 ✓ + apricot 淡底高亮。
  • 搜索无匹配展示空匹配小注样例。
API / 权限标注
  • GET /api/v1/admin/subjects?mode=…（agent 代理 / acquire 包销映射，随项目业务模式过滤；需 subject:read）
