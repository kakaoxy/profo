设计说明

关键实现决策与政策落点。

注 · 顶部 HUD「12 节点流程条」：已过节点打勾、当前节点高亮并显示「第 X/12 步」与「第 X 天」；节点可点击直达（评审用）。
· 先选身份再选现金再选房：刚需首套 / 置换改善 / 投资二套——决定贷款利率（首套公积金 2.6% / 商贷 3.05%，二套公积金 3.075% / 商贷 3.06%）、名下套数（0/1/1）与房产税口径（仅投资二套按年）；可动用现金提供 50/70/100/200/300 万预设档 + 自定义输入，不再写死 70 万。
· 自定义房源（新增）：挂牌价 / 面积 / 环线 / 税费条件（新房、满五唯一、满五不唯一、满二不唯一、不满 2 年全额增值税）全由用户填写，议价空间默认 5%，之后照常走资格核验与砍价。
· 贷款方式选择（新增，对齐 20260901 上海按揭政策表）：纯商贷 / 组合贷 / 纯公积金——首套首付 15%（商贷）/ 20%（组合贷·公积金）；二套外环内 25%、外环外（特殊区域口径）商贷 15% / 组合贷·公积金 20%；组合贷为默认，公积金演示额度上限 80 万，不足部分并入首付。
· 房源价格跨度 200 / 300 / 400 / 550 / 600 / 1600 万，覆盖内外环、新房/二手、满五唯一/不唯一、满二不唯一、不满 2 年全额增值税等税费情形；内外环继续作为限购判定与二套首付差异维度。
· 税费逐项单列：契税（首套 ≤140㎡ 1% / >140㎡ 1.5%；二套 ≤140㎡ 1% / >140㎡ 2%）、增值税（满 2 年免征；不满 2 年全额 5% + 附加税费 ≈ 增值税×12%≈0.6%）、卖方个税（满五唯一免征，否则核定 1%）、不动产登记费 80 元、中介费（服务费，与税费分开算）；投资二套另列按年房产税（≈成交价×70%×0.4%，高单价按 0.6%）。
· 中介费协商：行情 1%–2%，默认报 2%，谈成 1%（省下的是软装钱）。
· 首付口径 = 房款首付 + 买方全部交易税费（含中介费）；最终账单突出「首付多少、月供多少」，不展示购房总成本（顺应鼓励住房消费导向）。
· 限购问答树依 PRD §6.1（沪籍单身 1 套/家庭 2 套；非沪籍居住证满 5 年 1 套；社保满 1 年外环外不限、外环内 1 套；满 3 年外环内 2 套），名下套数由身份角色提供、不再重复提问。
· 砍价上限 = 该套房源议价空间（A6%/B5%/C3%/D8%/E4%/F5%），超线卖家叫停、亮明底线（如「最多让到 380 万」），只提供「接受底价 / 换房」——底线已出，买家不再有任何“加价”空间。第二轮选项按「第一轮报价是否越线」动态生成：越线后只有 加价缓和 / 按底线成交 / 继续硬压（必叫停），杜绝「刚拒绝 -6% 又谈成 -7%」的逻辑矛盾；成交确认后不存在任何“加价”入口。
· 「到手价」暗坑（新增）：价格谈定后，满五不唯一 / 不满 2 年等有卖方税费的房源，房东补一句「这价是到手价」——增值税/个税由此转嫁买方，默认感觉得罪人家就随口答应；算账页首次显示这笔钱，签约页合同条款锁定「反悔即违约」，「先问清」会弹出解释模态。
· 贷款审批环节：月供 > 家庭月收入 50% 触发银行风控拦截（拉长年限 / 追加首付 / 坚持硬上被拒 / 换房）；借款缺口超可借上限时引导换房，不留死按钮。
· 交房交割检查：水电煤/物业/户口逐项核验，户口未迁出可协商「尾款扣押」（上海惯例，押金最高不超合同价 5%）。
· 关键节点弹出「随申办 / 银行」事件 toast（资格通过、网签备案、批贷函、放款、交房），增强第一人称代入感。

免责声明：本原型为需求确认用的高保真设计稿，所有金额、税率、利率均为按 2026 上海公开口径的估算值，仅供演示。

本模拟器不收集用户真实个人信息；「信用贷」等选项仅为风险教育演示，绝不构成信贷建议。实际交易请以政府部门、银行与税务机关为准。模拟结果不构成任何法律或财务决策依据。
