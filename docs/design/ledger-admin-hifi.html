0本次重构遵循的设计契约

以下规则直接来自 DESIGN.md；括号内为本次改动的具体落法。四条硬约束决定了所有页面的观感。

配色 · 单色 chrome + 一个暖色强调

Ink #17191c Fog #f7f7f8 Dove #a3a6af Rust #5d2a1a Apricot #fbe1d1 Sky #d3e3fc
  • 1删除 emerald / amber / blue / purple 彩色实心图标圆——《资金账本》列表页与明细统计卡是重灾区。
  • 2彩色只保留三种声音：Rust（暖强调）、Apricot 与 Sky（唯二的彩色卡底）。
  • 3金额红/绿（中国习惯）只在数字本身出现，不作为 chrome、不铺底色。

字体 · Signifier 只做标题

  • 4页面 H1 用 Signifier 衬线 40px（DESIGN.md 规定衬线不得低于 40px），替换当前 text-2xl font-bold。
  • 5其余全部 Sohne 栈，微字重 430 / 450 / 480 取代 bold/regular 二分；从不 bold。
  • 6所有数字加 tabular-nums；全站 letter-spacing: -0.009em。

逐项改动清单

  • 画布　bg-muted → bg-fog；容器宽度统一 1200px。
  • 页头　text-2xl font-bold → font-display text-[40px] + 17px Ash 副标题。
  • 统计卡　去彩色图标圆，改单色描边小图标；仅净现金流用 Apricot 暖卡，其余白卡。
  • 统计卡数值　font-bold text-xl → 30px / weight 450 / tabular-nums；净现金流 ≥0 用 Rust、<0 用 Ink（与明细页 HeaderStats 口径一致）。
  • 搜索框　加前置放大镜图标、16px 圆角、Dove 描边。
  • 状态筛选　下拉 Select → 胶囊 Tab 组（Fog 底、激活 Ink 填充），带各状态计数。
  • 导出按钮　唯一的 Ink 填充胶囊；移除多余 outline 变体。
  • 表格容器　去边框 → rounded-cards + shadow-steep。
  • 表头　13px / weight 480 / Graphite，首字母不变大写。
  • 状态徽章　改 Steep 单色：在售＝Ink 填充、已售＝Dove、已签约/装修中＝Fog。
  • 金额展示　统一 ¥xxx.xx万 缩写，tabular-nums；净现金流/ROI 保留红/绿语义。
  • 行内操作　图标默认隐形、hover 显现，Graphite → Rust；点击不冒泡到整行跳转。
  • 分页　Fog 胶囊按钮、当前页 Ink 填充、36px 圆形按钮，与全局分页统一。
  • 复用　抽用 @/components/common 的 ListView / SearchBar，与 marketing 列表页共用骨架。

关键改动 · 层级 pill 的重做

现状的 7 级层级 pill 使用 红 / 琥珀 / 蓝 / 橙 / 天蓝 / 绿 / 紫 七色，是页面里最刺眼的旧风格残留，也违反 DESIGN.md「chrome 单色、彩色只留 Rust + 两个 wash」。 建议改为 Apricot → Rust 的 7 级暖色梯度：既是单色系（符合规范），又能一眼看出成本层级由浅到深，比彩虹更清楚地表达“层级”。
