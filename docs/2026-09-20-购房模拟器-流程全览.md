## 一、运行形态

- **单页状态机**：整个模拟器是一个页面（[index/index.ts](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/index/index.ts)），全部状态在一个 `SimState` 对象里（[constants.ts#L175-L300](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/constants.ts#L175-L300)），当前屏 = `S.scene`（38 个 `SceneKey`）。
- **推进方式**：点屏内按钮 → `data-act` → `handle(action)` 按优先级分发（[handlers.ts](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/handlers.ts)）：
  1. `handleSetup`（重置 / 身份 / 现金 / 选房 / 自定义 / 资格问答 / 换房）
  2. `handleFlow`（砍价 → 中介费 → 贷款 → 算账 → 筹钱 → 签约 → 过户交房）
  3. `handleRenov`（装修 14 屏）
  处理器就地改 `SimState`，然后 `ctx.nextScene(key)` / `ctx.render()` 触发整屏重绘。
- **渲染**：`buildScene(S)`（[scenes.ts](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/scenes.ts)）按 `S.scene` switch 到对应 `sceneXxx(S)` 纯函数，产出一组有序内容块（`blocks`）+ 一个主按钮（`primary`）；页面 HUD（12 节点线 / 时间条 / 压力值）由 [render.ts](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/render.ts) 组装。
- **进入即重开**：`onLoad → resetAll()`（[index.ts#L120-L124](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/index/index.ts#L120-L124)），新建初始状态并清空风险记录。进度不落盘，中途退出即白玩。
- **本地存储**：唯一 storage key 是 `houseSimRiskLog`（[riskLog.ts](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/riskLog.ts)），存 3 类风险确认记录，生命周期 = 一次模拟。

## 三、购房主线（24 屏，顺序即流程）

### 节点 0-1 · 开场与选房

| # | 屏（key） | 玩家做什么 | 关键分支 / 状态变化 |
|---|---|---|---|
| 1 | 开始 `start` | 看开场三卡 + 12 节点一览 | 主按钮「开始购房之旅」 |
| 2 | 你是谁 `role` | 选身份：刚需首套 / 置换改善 / 投资二套 | 决定利率、名下套数、税费口径；换身份重置中介费报价 2% |
| 3 | 亮家底 `cash` | 选现金档位或自定义输入 | `S.cash` 定格（重新选会作废已筹借款） |
| 4 | 看房 `select` | 从 6 套预设房源选一套，或进自定义 | 选定即重置砍价 / 到手价 / 拒批状态并重算税费；房源卡预标税费与可砍幅度 |
| 5 | 自定义房源 `custom` | 填挂牌价 / 面积，选环线 / 持有年限 / 是否唯一 / 取得方式（买卖或继承赠与） | 口径一改即时重算税费预览；继承/赠与个税按差额 20% |

### 节点 2 · 资格

| # | 屏 | 玩家做什么 | 关键分支 |
|---|---|---|---|
| 6 | 资格核验 `qa` | 依次回答户籍 → 居住证 → 社保年限 | 每答一题推进；答完出 `judge` 结果 |
| 7 | 资格结果 `blocked` | 看判定 | 通过 → 主按钮「去砍价」；不通过 → 可「仍然继续（会卡在网签）」或「换一套（`backSelect`）」「重新核验（`requalify`）」 |

### 节点 3 · 砍价与费用谈判

| # | 屏 | 玩家做什么 | 关键分支 |
|---|---|---|---|
| 8 | 砍价·第一轮 `nego1` | 三选一：直接还价 -6% / 试探 -3% / 先聊为什么卖 | 出价超过房东底线（`negotiable`）→ 置 `negoCap`，成交价封顶底线价 |
| 9 | 砍价·第二轮 `nego2` | 未越线：继续出价（净让幅）→ 成交；越线：房东叫停屏 | 叫停屏只有两个出口：接受底价成交 / 换一套（`backSelect`） |
| 10 | 成交·到手价 `nego3` | 有卖方税费（不满二 / 不唯一）时三选一：按到手价 / 先问清 / 按含税价 | 「按到手价」= 卖方税费转嫁买方（`netDeal=true`），弹风险确认；满五唯一 / 新房无此屏决策，直接确认成交 |
| 11 | 中介费 `feeNego` | 按 2% 或压到 1% | 计入买方税费合计 |

### 节点 4-5 · 贷款、算账、筹钱

| # | 屏 | 玩家做什么 | 关键分支 |
|---|---|---|---|
| 12 | 贷款方式 `loanType` | 选纯商贷 / 组合贷 / 纯公积金 + 首付档位（最低 / 30% / 50% / 全款） | 首付比例 = 身份 × 环线 × 贷款方式；纯公积金有额度上限（首套 240 万口径） |
| 13 | 算账 `funds` | 看全账单（首付 = 房款首付 + 全部税费） | 资金充足 → 直达签约；有缺口 → 进筹钱屏 |
| 14 | 筹钱 `borrow` | 三条渠道各补到缺口为止：亲友（上限 30 万）/ 提取公积金（20 万）/ 信用贷（20 万，监管红线） | 再点一次退回该渠道；「换套便宜点的」= `backSelect`；缺口超三渠道合计 70 万则置灰 |

### 节点 6-7 · 签约与贷款

| # | 屏 | 玩家做什么 | 关键分支 |
|---|---|---|---|
| 15 | 签约·居间协议 `sign` | 前 6 项逐项「写进合同 / 先不写」，或一键「都不写先签」 | 主按钮付定金（弹窗 + 定金刚则风险确认）→ 网签 |
| 16 | 网签·买卖合同 `signNet` | 后 6 项同上 | 主按钮付首付先付（弹窗 + 违约金 20% 风险确认）；**全款**跳过贷款两屏直达贷款合同 |
| 17 | 贷款方案 `loan` | 选还款年限 10 / 20 / 30 年 | 年限影响月供与总利息 |
| 18 | 贷款审批 `loanChk` | 月供超风控线（> 收入 50%）时四选一：追加首付 / 拉长到 30 年 / 换房 / 坚持硬上 | 硬上 → 银行拒批（`loanRejected`，材料时间白花）；通过 → 签贷款合同 |
| 19 | 贷款合同 `loanContract` | 补足剩余首付 | 付款弹窗 → 过户 |

### 节点 8-11 · 过户到交房

| # | 屏 | 玩家做什么 | 关键分支 |
|---|---|---|---|
| 20 | 过户递交 `transfer` | 等待审税（等待屏展开「在等谁」） | **爆雷点**：产调（抵押/查封）没写清在此爆 |
| 21 | 缴税领证 `deed` | 付税费（契税 + 中介费 + 登记费 + 转嫁税费） | 税费账单逐行展示；**爆雷点**：税费归属没写清 |
| 22 | 交房·交割检查 `handover` | 二选一：逐项核对全部结清 / 发现欠费户口问题 → 尾款扣押 1% | 交割 4 项：水电煤物业 / 户口 / 钥匙家具 / 维修资金 |
| 23 | 交割结算 `settle` | 结清尾款 | 扣押 → 付扣押确认（不占现金）；**爆雷点**：学位户口 / 欠费 / 家具清单没写清在此爆 |
| 24 | 完成总账 `final` | 看总账 | 三态见下节 |

### `final` 屏三态（终点恒为 `final`）

| 状态 | 触发 | 屏上内容 |
|---|---|---|
| 未装修 | 默认 | 总账 + 「开始装修 / 直接入住」两个入口 |
| 装修完成 | `renovDone && !renovSkipped` | 总账 + 装修完成横幅（实际花费 = 合同价 + 增项）+ 历时统计 |
| 跳过装修 | `renovDone && renovSkipped` | 总账 + 「交易完成 · 新家已定」横幅 |

总账内容（[scenes-close.ts#L152-L269](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/scenes-close.ts#L152-L269)）：「该掏的 → 实际掏的」对比、「经历周期 → 常规周期(90 天)」对比柱、学费清单（多花的每一笔）、带走清单（签约 12 项 + 交割 4 项）、风险确认记录；主按钮恒为「重来一次 · 换一条路」（`reset`）。无分享 / 无保存出口。

## 四、换房与重开的语义（`backSelect` / `toSelect`）

「换一套」（`backSelect`，出现在资格不过 / 谈崩 / 算账缺口 / 审批不过 / 筹钱屏）会**作废本轮全部交易判断**（[handlers-setup.ts#L23-L45](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/handlers-setup.ts#L23-L45)）：

- 退还全部已出款（定金 / 首付 / 税费），借款原路退回、清空渠道记录
- 清空：成交价 / 砍价结论 / 到手价 / 拒批标记 / 交割结论 / **签约 12 项结论**
- 回到看房屏

「重来一次」（`reset`）**只出现在 `final` 屏主按钮**（HUD 无全局重开入口）= `resetAll()`，一切归零并清空风险记录。

## 五、装修线（14 屏）

交易完成后从 `final` 进入；装修支出**独立记账**，不动购房现金。

| 屏（key） | 玩家做什么 | 关键机制 |
|---|---|---|
| 装修预算 `renovStart` | 选档位：半包 1000/㎡ / 全包起步 2000 / 主流 3000 / 品质 4000 | 合同基础价 = 档位单价 × 面积；确认开工：交易完成次日开工 |
| 设计 `renovDesign` | 选设计师：免费 / 独立 6000 / 全案 15000 | 设计费一次性计入合同价；决策屏不可跳过 |
| 签合同 `renovContract` | 13 项合同清单逐项「写进合同 / 明确不做」 | 合同价 = 预算 + 设计费 + 已定项；**「一键写清不能省的 N 项」按钮**是全模块最强提示；没定的项埋成增项雷 |
| 10 张上划卡（拆除→主材→水电→防水→木瓦→油漆→安装→保洁→通风→质保） | 每屏一张卡：工期 / 谁在做 / 提醒；点「下一步 +N 天」推进 | 到达埋雷阶段时**到站结算**：弹出增项单（金额 + 拖的天数），累计进 `renovExtra`；半包走「自购主材踩坑」口径 |
| 质保 `renovWarr` | 显示完工日 | 装修结束 |
| 完工总账 `renovDone` | 看装修三数 | 「签合同时的价 → 结账时的价」「计划工期 → 实际工期」、增项复盘（Top 增项单 + 决策记录）；完屑后回 `final`（装修完成态） |

增项雷点：主材（等货 30-45 天）、木瓦、安装三处（[renov-data.ts#L299-L313](file:///Users/wither-e/Desktop/profo/miniapp/pages/house-simulator/utils/renov-data.ts#L299-L313)）。装修口径：12 阶段，计划工期由各阶段名义天数累计，实际工期 = 完工日 − 开工日。
